mcut is an open-source video editing SDK for TypeScript apps. The current OSS
repo is strongest at project documents, headless timeline edits, editor
operators, React preview surfaces, browser media helpers, captions, CLI
workflows, and MCP tools.

mcut Studio, the desktop editor built on these packages, ships for macOS and
Linux from [GitHub Releases](https://github.com/mattppal/mcut/releases) and
hosts the live MCP bridge that agents connect to.

## Intro

- [Quickstart](/docs/quickstart): create a project document and inspect it with the CLI.
- [Install Studio](/docs/studio/install) covers downloading the desktop app and launching it the first time.
- [Connect Cursor](/docs/studio/connect-cursor) covers pointing an MCP client at the bridge inside Studio.
- [Project model](/docs/concepts/project-model): understand the JSON document mcut edits.
- [Package architecture](/docs/concepts/package-architecture): choose the package that owns your task.
- [SDK Reference](/docs/sdk): generated TypeScript API docs for public exports.

## Current state

mcut is alpha software. The packages are useful today, but the API is still
settling. Prefer commands and operators over editing project JSON by hand, and
check the generated SDK reference when you need exact signatures.

## For agents

Use [Agent instructions](/docs/agent-instructions) when an AI agent edits an
mcut project through the CLI, the stdio MCP server, or the live bridge in
Studio.
