## Types

### MediaProbe

```ts
interface MediaProbe {
  durationMs: number
  hasVideo: boolean
  hasAudio: boolean
  width?: number
  height?: number
  mimeType?: string
}
```

The result of `probeMedia`, duration, which tracks exist, optional dimensions, and MIME type.

### MediaOrigin

```ts
type MediaOrigin =
  | { kind: 'blob'; blob: Blob; name: string }
```

Where the bytes of a media file come from. Today the only member is a blob with a display name.

### MediaProberId

```ts
type MediaProberId = 'mediabunny'
```

The closed set of prober ids. Today the only member is `mediabunny`.

### MediaProber

```ts
interface MediaProber {
  id: MediaProberId
  probe(origin: MediaOrigin, signal?: AbortSignal): Promise<MediaProbe>
}
```

An engine that turns a `MediaOrigin` into a `MediaProbe`. `createAsset` accepts one so another engine can replace `mediabunnyProber` without changing its callers.

### MediaProbeErrorCode

```ts
type MediaProbeErrorCode = 'unreadable' | 'no-tracks' | 'no-duration'
```

Why a probe was rejected. `unreadable` when no demuxer or the browser can parse the file, `no-tracks` when it parses but has no audio or video track, `no-duration` when it has tracks but no measurable duration.

### MediaSourceLike

```ts
type MediaSourceLike = Blob | string
```

A media source given as a blob or a URL string.

### ThumbnailOptions

```ts
interface ThumbnailOptions {
  width?: number
```

Options for thumbnails, the output width and the source time to capture.

### ExtractAudioOptions

```ts
interface ExtractAudioOptions {
```

Options for `extractAudioToWav`, the output sample rate and channel count, a progress callback, and a signal that cancels the conversion and rejects with the signal's reason.

### ProjectStill

The PNG blob from `renderProjectStill`, with its pixel width, pixel height, and the ids of the elements drawn.

### RenderProjectStillOptions

Optional arguments for `renderProjectStill`. `soloElementId` draws only that element, including a multicam composite. `width` caps the PNG width and keeps the project aspect ratio.

### SceneChangeOptions

Optional arguments for `findSceneChanges`. `elementId` picks a video or multicam clip and defaults to the first multicam, then the first video clip. `source` picks a multicam source and defaults to `screen`, then the first video source. `startMs` and `endMs` bound the scan in timeline time and default to the clip span. `stepMs` defaults to 500. `sensitivity` runs from 0 to 1 and defaults to 0.5, where a change needs 30% of the picture to change. `maxChanges` defaults to 40 and keeps the largest changes.

### SceneChangeReport

The result of `findSceneChanges`. It names the element, the source, and the asset it read, the range, `stepMs`, `sensitivity`, the `threshold` fraction it used, and the number of samples. `changes` lists `{ timeMs, changed }` in timeline order. `segments` lists the `{ startMs, endMs }` stretches between changes. `truncated` is true when `maxChanges` dropped smaller changes.

### ContactSheetOptions

Optional arguments for `renderContactSheet`. It takes the same `elementId`, `source`, `startMs`, and `endMs` as `SceneChangeOptions`, plus `timesMs`, `count` (default 12), `columns` (default a square grid), and `thumbWidth` in pixels (default 320).

### ContactSheet

The PNG blob from `renderContactSheet`, with its pixel width and height, the column count, the element and source it read, and `tiles`, the timeline time of each tile in grid order.

### FaceSample

`FaceSample` is `{ sourceMs, box }`, one reading of `createLocalFaceDetector` at an integer source media time. `box` is the largest face as `{ x, y, w, h }` fractions of the frame, or `null` when the frame has none. It fits `FaceSample` from `@mcut/editor`, so `detect` output goes straight to `planCenterPerson`.
