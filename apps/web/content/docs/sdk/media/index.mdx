---
title: "@mcut/media"
description: "Media probing, thumbnails, audio analysis, preview pools, and export."
---

`@mcut/media` probes, decodes, and encodes media in the browser and serves frames and audio to the preview and export paths.

## Install

```sh
bun add @mcut/media
```

- [Types](/docs/sdk/media/types) covers types and Zod schemas exported by @mcut/media.
