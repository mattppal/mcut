## Classes

### AudioNotDecodableError

```ts
class AudioNotDecodableError extends Error {
  constructor(codec: string | undefined)
}
```

Error thrown when a file has an audio track but the browser has no decoder for its codec.

### MediaProbeError

```ts
class MediaProbeError extends Error {
  readonly name = 'MediaProbeError'
  readonly code: MediaProbeErrorCode
}
```

Error thrown by `probeMedia` and `createAsset` when a file cannot be read as media or has no playable track. `code` says which.

### PreviewMediaPool

```ts
class PreviewMediaPool implements FrameSource {
  constructor(private resolveAsset: (assetId: AssetId) => AssetRef | undefined)
  setAudioSources(sources: ReadonlyMap<ElementId, string> | undefined): void
  getAudioSources(): ReadonlyMap<ElementId, string> | undefined
  getFrame(assetId: AssetId, sourceTimeMs: number): CanvasImageSource | null
  sync(items: ActiveMediaItem[], options: PreviewSyncOptions): void
  pauseAll(): void
  dispose(): void
}
```

The approximate `FrameSource` for interactive preview. It keeps one pooled media element per asset in sync with the playback clock, plays `setAudioSources` URLs from a separate audio element while muting the asset's own audio, and decodes bitmaps for images.

### ScrubFrameCache

```ts
class ScrubFrameCache {
  constructor(
    private maxFrames = 150,
    private minGapMs = 90,
  )
  capture(source: HTMLVideoElement, timeMs: number): void
  nearest(timeMs: number): OffscreenCanvas | null
  get size(): number
  clear(): void
}
```

A bounded cache of downscaled video frames sorted by time, capturing opportunistically and serving the nearest frame while a seek is pending.
