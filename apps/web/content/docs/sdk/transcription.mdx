title: "@mcut/transcription"
description: "Transcript types, subtitle formats, caption generation, and transcript tools."
---

`@mcut/transcription` defines the transcript and provider types and converts transcripts into subtitles, caption elements, and edit plans.

## Install

```sh
bun add @mcut/transcription
```

## Types

### TranscribeInput

```ts
interface TranscribeInput {
  audio: Blob | ArrayBuffer | Uint8Array | string
  mimeType?: string
}
```

Audio handed to a provider as a blob, buffer, byte array, or URL string, with an optional MIME type.

### TranscribeOptions

```ts
interface TranscribeOptions {
  language?: string
  signal?: AbortSignal
}
```

Per-call transcription options, a language hint and an abort signal.

### TranscriptionProvider

```ts
interface TranscriptionProvider {
  readonly id: string
  transcribe(input: TranscribeInput, options?: TranscribeOptions): Promise<TranscriptResult>
}
```

A transcription backend with an id and a `transcribe` method that returns a normalized `TranscriptResult`.

### TranscriptResult

```ts
interface TranscriptResult {
  text: string
  language?: string
  durationMs?: number
  words: TranscriptWord[]
  segments: TranscriptSegment[]
}
```

Normalized transcription output with full text, optional language and duration, timed words, and timed segments.

### TranscriptSegment

```ts
interface TranscriptSegment {
  text: string
  startMs: number
  endMs: number
  speaker?: string
}
```

A timed span of transcript text in milliseconds, with an optional speaker label.

### TranscriptWord

```ts
interface TranscriptWord {
  text: string
  startMs: number
  endMs: number
  confidence?: number
  speaker?: string
}
```

One timed word in milliseconds, with optional confidence and speaker label.

### SubtitleCue

```ts
interface SubtitleCue {
  startMs: number
  endMs: number
  text: string
}
```

A subtitle cue with start and end in milliseconds and its text.

### BuildApplyCaptionsOptions

```ts
interface BuildApplyCaptionsOptions extends ToCaptionElementsOptions {
  trackId?: TrackId
  replace?: boolean
}
```

Options for `buildApplyCaptionsCommand`, adding a target track id and a replace flag to `ToCaptionElementsOptions`.

### CaptionElementInput

```ts
interface CaptionElementInput {
  type: 'caption'
  startMs: number
  durationMs: number
  text: string
  words?: CaptionWord[]
  style?: Partial<CaptionStyle>
}
```

A caption element without an id, ready for insertion through the `applyCaptions` command.

### GroupWordsOptions

```ts
interface GroupWordsOptions {
  maxChars?: number
  maxDurationMs?: number
  maxGapMs?: number
}
```

Limits for `groupWords`, maximum characters, maximum duration, and maximum silent gap per group.

### ToCaptionElementsOptions

```ts
interface ToCaptionElementsOptions extends GroupWordsOptions {
  style?: Partial<CaptionStyle>
  timeOffsetMs?: number
  sourceStartMs?: number
  sourceEndMs?: number
}
```

Options for `toCaptionElements`, adding a caption style, a time offset, and a source range to `GroupWordsOptions`.

### WordGroup

```ts
interface WordGroup {
  text: string
  startMs: number
  endMs: number
  words: TranscriptWord[]
}
```

A run of consecutive words with joined text and the span they cover.

### CaptionContentPatch

```ts
interface CaptionContentPatch {
  captionId: string
  text: string
  words?: CaptionWord[]
}
```

A computed caption text and words change for one caption, ready for an `updateElement` patch.

### CaptionMergeResult

```ts
interface CaptionMergeResult {
  startMs: number
  durationMs: number
  text: string
  words?: CaptionWord[]
}
```

The merged caption produced by `mergeCaptions`, with start, duration, text, and optional words.

### CaptionSplitResult

```ts
interface CaptionSplitResult {
  left: { text: string; words: CaptionWord[]; durationMs: number }
  right: {
    startMs: number
    durationMs: number
    text: string
    words: CaptionWord[]
  }
}
```

The two halves produced by `splitCaptionAtWord`, each with text, words, and duration.

### MappedWord

```ts
interface MappedWord {
  word: CaptionWord
  startChar: number
  endChar: number
}
```

A caption word together with the character range it occupies in the caption text.

### TranscriptCaption

```ts
interface TranscriptCaption {
  id: string
  startMs: number
  durationMs: number
  text: string
  words?: CaptionWord[]
}
```

The caption element shape the transcript tools operate on, with word timings relative to `startMs`.

### TranscriptMatch

```ts
interface TranscriptMatch {
  captionId: string
  startChar: number
  endChar: number
  firstWord?: number
  lastWord?: number
  timeMs: number
  endTimeMs: number
}
```

A search hit inside one caption with its character range, the mapped word span when available, and absolute start and end times.

## Functions

### toSrt

```ts
function toSrt(input: TranscriptResult | SubtitleCue[]): string
```

Formats cues, or the cues derived from a transcript, as SubRip text with comma millisecond separators.

### toVtt

```ts
function toVtt(input: TranscriptResult | SubtitleCue[]): string
```

Formats cues, or the cues derived from a transcript, as WebVTT text with a `WEBVTT` header.

### transcriptToCues

```ts
function transcriptToCues(result: TranscriptResult): SubtitleCue[]
```

Returns display cues from provider segments, or from grouped words, or one cue over the full duration when only text exists.

### buildApplyCaptionsCommand

```ts
function buildApplyCaptionsCommand(
  result: TranscriptResult,
  options: BuildApplyCaptionsOptions = {},
): AnyCommand
```

Returns an `applyCaptions` command whose captions come from `toCaptionElements`, targeting an optional track and replacing existing captions by default.

### groupWords

```ts
function groupWords(words: TranscriptWord[], options: GroupWordsOptions = {}): WordGroup[]
```

Splits timed words into caption-sized groups, starting a new group at the character, duration, or gap limit and on speaker change.

### toCaptionElements

```ts
function toCaptionElements(
  result: TranscriptResult,
  options: ToCaptionElementsOptions = {},
): CaptionElementInput[]
```

Converts a transcript into caption element inputs, grouping words or segments within the source range, shifting times by the offset, and clamping overlaps.

### mapCaptionWords

```ts
function mapCaptionWords(caption: TranscriptCaption): MappedWord[] | null
```

Locates each timed word inside the caption text in order and returns their character ranges, or `null` when the words no longer match the text.

### mergeCaptions

```ts
function mergeCaptions(
  a: TranscriptCaption,
  b: TranscriptCaption,
): CaptionMergeResult
```

Merges two captions in either order into one spanning both, keeping word timings only when both sides carry them.

### replaceAllMatches

```ts
function replaceAllMatches(
  captions: readonly TranscriptCaption[],
  query: string,
  replacement: string,
): CaptionContentPatch[]
```

Replaces every occurrence of the query across the captions and returns one content patch per changed caption.

### replaceMatch

```ts
function replaceMatch(
  caption: TranscriptCaption,
  match: TranscriptMatch,
  replacement: string,
): CaptionContentPatch
```

Replaces one search match and returns a patch where replacement tokens take over the matched words' time span in proportion to their length.

### retypeWord

```ts
function retypeWord(
  caption: TranscriptCaption,
  wordIndex: number,
  newText: string,
): CaptionContentPatch | null
```

Replaces the text of one word in place while keeping its timing, or returns `null` when the words no longer map to the text.

### searchCaptions

```ts
function searchCaptions(
  captions: readonly TranscriptCaption[],
  query: string,
): TranscriptMatch[]
```

Runs a case-insensitive substring search across captions and returns each hit with its character range, word span, and absolute time.

### splitCaptionAtWord

```ts
function splitCaptionAtWord(
  caption: TranscriptCaption,
  wordIndex: number,
): CaptionSplitResult | null
```

Splits a caption immediately before the given word into two captions, or returns `null` when either half would be invalid or too short.
