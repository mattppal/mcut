---
title: "@mcut/timeline"
description: "Project model, schemas, commands, engine, and pure timeline helpers."
---

`@mcut/timeline` defines the project document, validates and migrates it, and runs edits through commands and the `EditorEngine`.

## Install

```sh
bun add @mcut/timeline
```
