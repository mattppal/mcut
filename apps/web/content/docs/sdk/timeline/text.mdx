## Types

### TextRun

```ts
type TextRun = z.infer<typeof textRunSchema>
```

A text run as inferred from `textRunSchema`.

### TextRunStyle

```ts
type TextRunStyle = z.infer<typeof textRunStyleSchema>
```

Run style overrides as inferred from `textRunStyleSchema`.

### TextRunStylePatch

```ts
type TextRunStylePatch = {
  [K in keyof TextRunStyle]?: TextRunStyle[K] | null
}
```

A partial `TextRunStyle` for `applyRunStyle`, where `null` clears an override.

## Schemas

### textRunSchema

```ts
const textRunSchema = z
  .object({
    start: z.number().int().nonnegative(),
    end: z.number().int().positive(),
    style: textRunStyleSchema,
  })
  .refine((run) => run.end > run.start, 'run end must be after its start')
```

Zod schema for a text run, a half-open character range with `end` after `start` and its style overrides.

### textRunStyleSchema

```ts
const textRunStyleSchema = z.object({
  color: z.string().optional(),
  fontWeight: z.number().int().min(100).max(1000).optional(),
  fontStyle: z.enum(['normal', 'italic']).optional(),
})
```

Zod schema for the per-run overrides a text element allows, color, font weight, and font style.

### cropSchema

```ts
const cropSchema = z
  .object({
    x: z.number().min(0).max(1),
    y: z.number().min(0).max(1),
    w: z.number().positive().max(1),
    h: z.number().positive().max(1),
  })
  .refine((c) => c.x + c.w <= 1.0001 && c.y + c.h <= 1.0001, 'crop must stay inside the source')
```

Zod schema for a source-space crop, a normalized origin and size from 0 to 1 that stay inside the source.

### shadowSchema

```ts
const shadowSchema = z.object({
  color: z.string().default('rgba(0, 0, 0, 0.6)'),
  blur: z.number().nonnegative().default(12),
  offsetX: z.number().default(0),
  offsetY: z.number().default(6),
})
```

Zod schema for a soft drop shadow, a color, a non-negative blur, and x and y offsets, all with defaults.

### strokeSchema

```ts
const strokeSchema = z.object({
  color: z.string().default('#000000'),
  width: z.number().positive(),
})
```

Zod schema for an outline drawn on the owner's silhouette, a color defaulting to black and a positive width.

### frameStyleSchema

```ts
const frameStyleSchema = z.object({
  crop: cropSchema.optional(),
  cornerRadius: z.number().min(0).max(0.5).optional(),
  stroke: strokeSchema.optional(),
  shadow: shadowSchema.optional(),
})
```

Zod schema for the frame around a piece of media, shared by video, image, and multicam elements and by layout slots. The crop picks the source region, the corner radius is a fraction of the frame's shorter side, the stroke is an inside border, and the shadow is filled behind the frame.

## Functions

### applyRunStyle

```ts
function applyRunStyle(
  runs: readonly TextRun[],
  start: number,
  end: number,
  patch: TextRunStylePatch,
  textLength: number,
): TextRun[]
```

Returns the runs with the patch merged into every override inside the range, splitting runs at the range boundaries and leaving runs outside it unchanged.

### getRunStyleAt

```ts
function getRunStyleAt(runs: readonly TextRun[], offset: number): TextRunStyle
```

Returns the style overrides of the run that contains a character offset, or an empty object.

### normalizeRuns

```ts
function normalizeRuns(runs: readonly TextRun[], textLength: number): TextRun[]
```

Returns the runs clamped to the text, sorted, stripped of empty ranges and empty styles, and merged where neighbors share a style.

### shiftRunsForEdit

```ts
function shiftRunsForEdit(
  runs: readonly TextRun[],
  oldText: string,
  newText: string,
): TextRun[]
```

Returns the runs remapped across a text edit, shifting offsets after the changed region and clamping offsets inside it, so typing inside a styled run extends it.
