## Types

### ElementTypeEntry

```ts
interface ElementTypeEntry {
  type: string
  fullSchema: z.ZodType
  inputSchema: z.ZodType
  keyframeable: readonly string[]
  onSplit?: (context: {
    element: Record<string, unknown>
    left: Record<string, unknown>
    right: Record<string, unknown>
    offsetMs: number
  }) => void
  validate?: (project: unknown, element: Record<string, unknown>) => void
  describe?: (element: Record<string, unknown>, project: unknown) => string
  frameRequests?: (
    project: unknown,
    element: Record<string, unknown>,
    timelineMs: number,
  ) => Array<{ assetId: string; sourceTimeMs: number }>
}
```

A registered element type, its composed schemas, keyframeable properties, and optional split, validate, describe, and frame request hooks.

## Constants

### PROJECT_VERSION

```ts
const PROJECT_VERSION = 1
```

The format version written into new and serialized projects.

## Functions

### migrateProject

```ts
function migrateProject(data: unknown): unknown
```

Upgrades a persisted project document to `PROJECT_VERSION`, treating documents without a version as version 1, and throws `ProjectFormatError` for invalid or newer documents.

### getElementType

```ts
function getElementType(type: string): ElementTypeEntry | undefined
```

Returns the registry entry for an element type, or `undefined`.

### listElementTypes

```ts
function listElementTypes(): ElementTypeEntry[]
```

Returns every registered element type entry.

### createProject

```ts
function createProject(options: CreateProjectOptions = {}): Project
```

Returns a new project with the given or default id, name, 1920 by 1080 size, and 30 fps, holding one empty track with the id `t-default`.

### parseProject

```ts
function parseProject(data: unknown): Project
```

Migrates an untrusted project document to the current format and validates it, throwing `ProjectFormatError` for documents from a newer version.

### registerTimelineElementType

```ts
function registerTimelineElementType(config: ElementTypeConfig): void
```

Registers a custom element type by composing its own fields with the shared id, type, and timing fields, and throws when the type already exists.

## Classes

### ProjectFormatError

```ts
class ProjectFormatError extends Error {
  readonly code: 'newer-version' | 'missing-migration' | 'invalid-document'
  constructor(code: ProjectFormatError['code'], message: string)
}
```

Error thrown for project documents that are not objects, come from a newer version, or lack a migration, with a matching `code`.
