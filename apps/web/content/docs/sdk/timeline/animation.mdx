## Schemas

### zoomPresetSchema

```ts
const zoomPresetSchema = z.object({
  name: z.string().min(1),
  durationMs: z.number().int().min(100).default(600),
  tracks: z.partialRecord(z.enum(ZOOMABLE_PROPERTIES), z.array(zoomKeySchema).min(2)),
})
```

Zod schema for a zoom preset, a name, a default duration of at least 100 ms, and per-property tracks of at least two normalized keys.

### animationPresetOptionsSchema

```ts
const animationPresetOptionsSchema = z.object({
  durationMs: z.number().int().min(50).optional(),
  direction: z.enum(['up', 'down', 'left', 'right']).optional(),
  intensity: z.number().min(0.1).max(4).optional(),
})
```

Zod schema for preset options, a duration of at least 50 ms, a direction, and an intensity from 0.1 to 4.

### animationPresetSchema

```ts
const animationPresetSchema = z.enum([
  'fade-in',
  'slide-in',
  'pop-in',
  'scale-in',
  'zoom-in',
  'whip-in',
  'blur-in',
  'fade-out',
  'slide-out',
  'pop-out',
  'zoom-out',
  'whip-out',
  'blur-out',
  'ken-burns',
  'punch-zoom',
  'pulse',
  'breathe',
  'float',
  'sway',
  'shake',
])
```

Zod schema for the twenty preset names, seven entrances, six exits, and seven combined or looping motions.

## Functions

### captureZoomPreset

```ts
function captureZoomPreset(
  element: TimelineElement,
  name: string,
  fromLocalMs?: number,
  toLocalMs?: number,
): ZoomPreset | null
```

Returns a zoom preset built from the zoomable keyframes between two element-local times, normalized against each track's first keyframe, or `null` when no track has two keyframes in the range.

### expandZoomPreset

```ts
function expandZoomPreset(
  element: TimelineElement,
  preset: ZoomPreset,
  atLocalMs: number,
  durationMs?: number,
): KeyframeMap
```

Returns the element's keyframe map with the preset expanded into absolute keyframes from `atLocalMs`, where scale keys multiply and position keys offset the animated value at that time, replacing keyframes inside the window.

### expandAnimationPreset

```ts
function expandAnimationPreset(
  element: TimelineElement,
  preset: AnimationPreset,
  options: AnimationPresetOptions = {},
): KeyframeMap
```

Returns the element's keyframe map with the preset's keyframes merged in, using the default duration, direction, and intensity unless options override them.
