## Types

### AssetId

```ts
type AssetId = `a-${string}`
```

A branded asset id string with the `a-` prefix.

### ElementId

```ts
type ElementId = `e-${string}`
```

A branded element id string with the `e-` prefix.

### GroupId

```ts
type GroupId = `g-${string}`
```

A branded group id string with the `g-` prefix.

### MarkerId

```ts
type MarkerId = `m-${string}`
```

A branded marker id string with the `m-` prefix.

### TrackId

```ts
type TrackId = `t-${string}`
```

A branded track id string with the `t-` prefix.

### AssetKind

```ts
type AssetKind = AssetRef['kind']
```

The media kind of an asset, video, audio, or image.

### AssetRef

```ts
type AssetRef = z.infer<typeof assetRefSchema>
```

A project asset as inferred from `assetRefSchema`.

### AudioElement

```ts
type AudioElement = z.infer<typeof audioElementSchema>
```

An audio element as inferred from `audioElementSchema`.

### AngleCutRef

```ts
type AngleCutRef = MulticamElement['angles'][number]
```

One entry of a multicam element's `angles` list, the source clock time a layout takes effect and the layout id.

### CaptionElement

```ts
type CaptionElement = z.infer<typeof captionElementSchema>
```

A caption element as inferred from `captionElementSchema`.

### CaptionStyle

```ts
type CaptionStyle = z.infer<typeof captionStyleSchema>
```

Caption styling as inferred from `captionStyleSchema`.

### CaptionWord

```ts
type CaptionWord = z.infer<typeof captionWordSchema>
```

A timed caption word as inferred from `captionWordSchema`.

### CreateProjectOptions

```ts
interface CreateProjectOptions {
  id?: string
  name?: string
  width?: number
  height?: number
  fps?: number
}
```

Optional id, name, size, and fps for `createProject`.

### ElementType

```ts
type ElementType = TimelineElement['type']
```

The `type` field of the six element kinds, `video`, `audio`, `image`, `text`, `caption`, and `multicam`.

### ImageElement

```ts
type ImageElement = z.infer<typeof imageElementSchema>
```

An image element as inferred from `imageElementSchema`.

### Marker

```ts
type Marker = z.infer<typeof markerSchema>
```

A project marker as inferred from `markerSchema`.

### MulticamElement

```ts
type MulticamElement = z.infer<typeof multicamElementSchema>
```

A multicam element as inferred from `multicamElementSchema`.

### MulticamSource

```ts
type MulticamSource = z.infer<typeof multicamSourceSchema>
```

One synced source of a multicam element, a role key, an asset id, and `offsetMs`, the source media time that plays at source clock time 0. A source with an audio asset is audio-only and is never drawn.

### TimelineElement

```ts
type TimelineElement =
  | VideoElement
  | AudioElement
  | ImageElement
  | TextElement
  | CaptionElement
  | MulticamElement
```

The closed union of the six element kinds.

### TimelineElementDraft

```ts
type TimelineElementDraft =
  | WithOptionalId<VideoElement>
  | WithOptionalId<AudioElement>
  | WithOptionalId<ImageElement>
  | WithOptionalId<TextElement>
  | WithOptionalId<CaptionElement>
  | WithOptionalId<MulticamElement>
```

The output of `elementInputSchema`, a parsed element with every default applied and only `id` still optional.

### TimelineElementInput

```ts
type TimelineElementInput =
  | WithOptionalId<z.input<typeof videoElementSchema>>
  | WithOptionalId<z.input<typeof audioElementSchema>>
  | WithOptionalId<z.input<typeof imageElementSchema>>
  | WithOptionalId<z.input<typeof textElementSchema>>
  | WithOptionalId<z.input<typeof captionElementSchema>>
  | WithOptionalId<z.input<typeof multicamElementSchema>>
```

The union of the element input shapes, where `id` is optional and defaulted fields may be omitted.

### Track

### Transform


### VideoElement

```ts

```

### Voice

```ts
type Voice = z.infer<typeof voiceSchema>
```

Voice cleanup mix as inferred from `voiceSchema`, whether it is on and how much cleaned audio to blend in.

## Functions

### createAssetId

```ts
const createAssetId = (): AssetId => `a-${randomSuffix()}`
```

Returns a new random `AssetId`.

### createElementId

```ts
const createElementId = (): ElementId => `e-${randomSuffix()}`
```

Returns a new random `ElementId`.

### createGroupId

```ts
const createGroupId = (): GroupId => `g-${randomSuffix()}`
```

Returns a new random `GroupId` shared by elements that move and edit as one item.

### createLayoutId

```ts
const createLayoutId = (): string => `lay-${randomSuffix()}`
```

Returns a new random id for a multicam layout.

### createLinkId

```ts
const createLinkId = (): string => `l-${randomSuffix()}`
```

Returns a new random link id shared by linked elements such as a video and its detached audio.

### createMarkerId


### createProjectId

### createTrackId

