---
title: "@mcut/compositor"
description: "Frame rendering backends, element geometry, text layout, and transition renderers."
---

`@mcut/compositor` renders a project frame to a canvas through a Canvas 2D or WebGPU backend and exposes the geometry used for on-canvas handles.

## Install

```sh
bun add @mcut/compositor
```
