## Constants

### TEXT_PRESETS

```ts
const TEXT_PRESETS: TextPreset[]
```

Built-in text presets, a title, a subtitle, a lower third, and a pop label.

### PLATFORM_PRESETS

```ts
const PLATFORM_PRESETS: PlatformPreset[]
```

Delivery presets for YouTube, YouTube 4K, Shorts, TikTok, Reels, and square feeds, read by `mcut new --preset` and the agent skill.

## Functions

### addTextAtPlayhead

```ts
function addTextAtPlayhead(engine: EditorEngine, text = 'Your text'): ElementId
```

Inserts a default text element at the playhead through `insertElementAtPlayhead` and returns its id.

### allElementIds

```ts
function allElementIds(engine: EditorEngine): `e-${string}`[]
```

Returns every element id in the project across all tracks.

### clipEdges

```ts
function clipEdges(engine: EditorEngine): number[]
```

Returns every clip start and end time plus zero, sorted ascending.

### createSequentialVideoCollage

```ts
function createSequentialVideoCollage(
  engine: EditorEngine,
  options: SequentialVideoCollageOptions,
): SequentialVideoCollageResult
```

Builds a collage where each video plays in turn in its own slot, with frozen frames before and after its active clip and its audio on one shared lane.

### duplicateElement

```ts
function duplicateElement(engine: EditorEngine, elementId: ElementId): ElementId | null
```

Adds a copy of the element in the nearest free slot after it on the same track, selects the copy, and returns its id or `null`.

### duplicateSelection

```ts
function duplicateSelection(engine: EditorEngine): void
```

Duplicates every selected element after itself in one transaction, skipping elements with no room, and selects the copies.

### elementForAsset

```ts
function elementForAsset(engine: EditorEngine, asset: AssetRef): TimelineElementInput
```

Returns the default timeline element for a media bin asset, sized to fit the project canvas.

### elementForTextPreset

```ts
function elementForTextPreset(engine: EditorEngine, preset: TextPreset): TimelineElementInput
```

Returns a text element input built from a `TextPreset`, with a box 70 percent of the project width and the preset's style and vertical offset.

### fitCanvasToVideoCollage

### planZoomAtPlayhead

```ts
function planZoomAtPlayhead(
  element: ZoomableElement,
  zoom: keyof typeof ZOOM_REGION_PRESETS | ZoomShape,
  playheadMs: number,
): CommandOfType<'addZoomRegion'>
```

Returns an `addZoomRegion` command that starts the preset at the playhead in element-local time, moved earlier when the zoom would run past the element. On a multicam the zoom targets the `screen` source, or the first source when there is no `screen`.

### planZoomRegionDrag

```ts
function planZoomRegionDrag(
  element: ZoomableElement,
  zoom: ZoomRegion,
  mode: ZoomRegionDragMode,
  deltaMs: number,
): ZoomRegion
```

Returns the zoom region after a drag of `deltaMs`. Ramps stay at least 1 ms long and the hold stays at least 0 ms. Within those limits a move, start, or end drag keeps the zoom inside the element and clear of other zooms on its target, which pulls a zoom that a split or trim left running past an edge back inside. A ramp drag keeps the span, so on such a zoom `updateZoomRegion` rejects the result.

### planSilenceCuts

```ts
function planSilenceCuts(
  project: Project,
  elementId: string,
  transcript: SilenceCutTranscript,
  options: SilenceCutOptions = {},
): SilenceCutPlan
```

Cuts the silences between transcript words out of one clip with source audio, playing forward at 1x, applying splits and ripple deletes last to first, and returns the commands and resulting project. A multicam is cut on its audio source before volume, fades, and mute. A time remap or reverse playback is rejected. A multicam with no audio source fails until `setMulticamAudio`.

### applyCommands

```ts
function applyCommands(engine: EditorEngine, commands: readonly BuiltinCommand[]): void
```

Dispatches the commands in order inside one transaction, so the batch becomes a single undo entry. Each command passes through `withPlayheadDefaults` first.

### withPlayheadDefaults

```ts
function withPlayheadDefaults(engine: EditorEngine, command: BuiltinCommand): BuiltinCommand
```

Returns an `applyAnimationPreset` command without `atMs` with `atMs` set to the playhead's element-local time when the playhead is on the clip. An out preset needs the playhead past the clip start. Any other command, or a playhead off the clip, comes back unchanged, so the preset falls back to the clip edge.

### summarizeEngine

```ts
function summarizeEngine(engine: EditorEngine): string
```

Returns the `summarizeProject` text for the engine's project followed by the playhead position, playing state, and selection.

### lintProject

```ts
function lintProject(project: Project): LintIssue[]
```

Reports cross-entity problems that `parseProject` accepts, such as elements that reference missing assets, links with one member, empty tracks, and empty captions.

### getPlatformPreset

```ts
function getPlatformPreset(id: string): PlatformPreset | undefined
```
