---
title: "@mcut/editor"
description: "Timeline operators, clip gesture helpers, and silence cut planning."
---

`@mcut/editor` provides named timeline operators, gesture math for clip drags, and silence cut planning on top of `@mcut/timeline`.

## Install

```sh
bun add @mcut/editor
```

## Pages

- [Types](/docs/sdk/editor/types) covers types and Zod schemas exported by @mcut/editor.
- [Functions](/docs/sdk/editor/functions) covers functions and constants exported by @mcut/editor.
- [Operators](/docs/sdk/editor/operators) covers the closed operator table, its ids, and the functions that list and run operators.
