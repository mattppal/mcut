---

`@mcut/transcription` defines the transcript and provider types and converts transcripts into subtitles, caption elements, and edit plans.

## Install

```sh
bun add @mcut/transcription
```

## Pages

- [Types](/docs/sdk/transcription/types) covers types and Zod schemas exported by @mcut/transcription.
- [Functions](/docs/sdk/transcription/functions) covers subtitle formatting, caption building, and transcript search and edit functions.
