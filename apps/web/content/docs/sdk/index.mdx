## Conventions

Each package page opens with a one-line purpose and an install command, then
lists exports grouped as types, schemas, constants, functions, classes, hooks,
and components. Signatures are copied from the package source. Larger
packages split across several pages with an index that links them.

The pages are maintained by hand alongside the source.
