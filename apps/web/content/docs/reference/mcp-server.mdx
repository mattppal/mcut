title: MCP server
description: Expose mcut project state, editor operators, and command tools to MCP clients.
---

`@mcut/mcp-server` exposes mcut editing to any MCP client. It can target a local
project JSON file or the editor running in mcut Studio.

## Live bridge in Studio

The desktop app hosts the live bridge. Open Studio, then connect a client to the
MCP URL from the app's MCP menu, `http://127.0.0.1:44737/mcp?token=<token>`.
[Connect Cursor](/docs/studio/connect-cursor) covers the menu, the `mcp.json`
entry, and the fixed port. Every tool below marked live bridge only works
through this URL. A browser tab connected to a standalone
[bridge](/docs/reference/bridge) process serves the same tools for developers
working on Studio itself.

## Stdio project server

```sh
bunx @mcut/mcp-server project.mcut.json
```

The project file defaults to `project.mcut.json` or `$MCUT_PROJECT`. The server
creates the file when missing and writes it after successful edits.

## Static tools

The published server registers sixteen static tools. The live bridge handles
three more in the editor, `list_commands`, `apply_commands`, and
`run_operator`, which together with the sixteen form the nineteen-tool agent
profile. Studio serves the profiles inside the desktop app, with a catalog at
`app://studio/tools`, at `app://studio/tools.json` and
`app://studio/tools.agent.json`. The full profile
is at `app://studio/tools.full.json` and the raw command profile at
`app://studio/tools.commands.json`.

| Tool | Purpose |
| --- | --- |
| `get_summary` | Compact project summary. Read this before editing. |
| `get_project` | Full serializable project JSON. |
| `get_media_context` | Project, playback, selection, asset, track, element, marker, and transcript metadata. |
| `get_audio_activity` | Live bridge only. Sound and silence windows for one video or audio clip in source time. |
| `get_transcript` | Caption-derived transcript. Never starts transcription. |
| `search_transcript` | Find spoken words or phrases with timeline times. |
| `ensure_transcript` | Live bridge only. Transcribe the target clip in the editor and apply word-timed captions. |
| `list_commands` | Live bridge only. Every raw timeline command schema. |
| `apply_commands` | Live bridge only. Apply several commands in one undoable transaction. |
| `apply_captions` | Turn a transcript into caption elements as one undoable edit. |
| `apply_silence_cuts` | Cut transcript silence out of one clip as one undoable edit. |
| `lint_project` | Cross-entity problems `parseProject` cannot reject, each with a severity and code. |
| `list_zooms` | Every zoom region with its element, timing, target, easing, and motion blur. |
| `edit_zooms` | Add, update, or remove zoom regions as one undoable edit. |
| `list_presets` | Platform delivery presets with dimensions, fps, and safe areas. |
| `list_operators` | List available UI-level editor operators. |
| `run_operator` | Live bridge only. Run an operator by id. |
| `list_actions` | Live bridge only. List editor actions. |
| `run_action` | Live bridge only. Run an editor action by id. |
| `undo` | Undo the most recent edit. |
| `redo` | Redo the most recently undone edit. |

## Generated operator tools

Every operator in the `@mcut/editor` operator table becomes an MCP tool named:

```text
operator_<operator-id-with-non-tool-characters-replaced>
```

For example, `edit.splitSelectionAtPlayhead` becomes
`operator_edit_splitSelectionAtPlayhead`.

Prefer operator tools for UI-parity edits because they understand playback,
selection, and editor context.

In live bridge mode, prefer high-level actions when they exist:

- Remove spoken-word silence with `run_action` and `actionId:
  "transcript.remove-silence"` after `ensure_transcript` has produced word-timed
  captions.
- Open from black and close to black with `run_action` and `actionId:
  "effects.fade-open-close"` so the built-in animation presets are used.

Do not fall back to `ffmpeg` or shell audio analysis for agent edits that mcut
tools can perform.

## Generated command tools

Every command in the `@mcut/timeline` command table also becomes an MCP tool.
The command description becomes the tool description and the zod payload schema
becomes the MCP input schema.

Use command tools for exact project mutations when you already know the target
ids and payload.
